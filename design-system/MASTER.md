# Medication Tracker — Master Design System

**Source of truth** for every UI decision. Page-specific overrides live in
`design-system/pages/<page-name>.md` and take precedence over this file only
for that page.

Generated by [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
`--design-system --variance 4 --motion 6 --density 3`, then reasoned against the
project's warmth/semi-formal/uncommon-fonts constraints.

---

## 1. Voice + tone

Warm, welcoming, semi-formal. This app cares for people taking medication
that keeps them alive. The interface should feel like a trusted family friend —
not a hospital form and not a cheerful app.

- **Do:** short sentences, plain English, kind phrasing ("Take Metformin now"
  not "Administer Metformin dose"), sparing punctuation.
- **Don't:** clinical jargon, exclamation marks, emoji, ALL CAPS, marketing copy.

---

## 2. Typography

**Chosen pairing: Fraunces (headings) + Instrument Sans (body)**

Both are Google Fonts and uncommon on SaaS. Fraunces is optical-size aware,
giving hero weights genuine warmth without sacrificing clarity at small sizes.
Instrument Sans is humanist and calm, ideal for body copy at 17px+.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400;9..144,500;9..144,600;9..144,700&family=Instrument+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">
```

```css
--font-heading: 'Fraunces', 'Iowan Old Style', Georgia, serif;
--font-body: 'Instrument Sans', -apple-system, BlinkMacSystemFont, sans-serif;
--font-mono: ui-monospace, 'SF Mono', Menlo, monospace;
```

**Scale** (rem base = 16px):

| Role         | Size    | Weight | Line-height | Font       | Notes                     |
|--------------|---------|--------|-------------|------------|---------------------------|
| Hero         | 44/56px | 600    | 1.05        | Fraunces   | Optical-size auto         |
| H1           | 32/40px | 600    | 1.15        | Fraunces   |                           |
| H2           | 24/30px | 600    | 1.2         | Fraunces   |                           |
| H3           | 20/26px | 600    | 1.3         | Fraunces   |                           |
| Body Large   | 18/28px | 400    | 1.55        | Instrument | Primary reading size      |

### Accessibility contract per theme

All theme × role combinations must satisfy:

- Body text (`--text` on `--surface-page`): **≥ 4.5:1**
- Muted text (`--text-muted`): **≥ 4.5:1** for meaningful content, **≥ 3:1** for decoration only
- Interactive text on accent (`--accent-on` on `--accent`): **≥ 4.5:1**
- Focus ring (`--ring`): **≥ 3:1** against `--surface-page`
- Border on card: distinguishable in both light and dark themes

`high-contrast` promotes every ratio to AAA.

## 4. Shape + spacing

**No hard edges.** Softness is a first-class design signal in this product.

```css
--radius-xs:  8px;
--radius-sm:  12px;    /* cards, buttons, inputs — never smaller */
--radius-md:  16px;
--radius-lg:  24px;    /* hero cards, sheets */
--radius-xl:  32px;
--radius-pill: 999px;
```

**Spacing** — 4px base grid, spacious density (variance 3):

```css
--space-1:  4px;
--space-2:  8px;
--space-3:  12px;
--space-4:  16px;
--space-5:  24px;
--space-6:  32px;
--space-7:  48px;
--space-8:  64px;
--space-9:  96px;
```

Card padding defaults to `--space-6` (32px). Page gutters `--space-5` (24px) on mobile, `--space-7` (48px) on desktop. Vertical rhythm between sections `--space-8` (64px).

## 5. Elevation

Soft UI Evolution — subtle shadows, never neumorphic.

```css
--shadow-none: none;
--shadow-1: 0 1px 2px rgba(23, 20, 13, 0.04), 0 1px 3px rgba(23, 20, 13, 0.06);
--shadow-2: 0 2px 4px rgba(23, 20, 13, 0.05), 0 4px 12px rgba(23, 20, 13, 0.08);
--shadow-3: 0 8px 24px rgba(23, 20, 13, 0.10);
--shadow-focus: 0 0 0 4px color-mix(in oklab, var(--ring) 25%, transparent);
```

Cards use `--shadow-1` at rest, `--shadow-2` on hover. Modals `--shadow-3`.
In `twilight`, use rgba with a warm-black base `rgba(11, 10, 15, 0.4)` scale.

## 6. Motion

Standard tier (motion dial 6/10). All animations respect `prefers-reduced-motion`.

```css
--dur-instant: 100ms;
--dur-fast:    180ms;
--dur-base:    240ms;   /* micro-interactions */
--dur-slow:    360ms;   /* card entrance, hovers */
--dur-page:    280ms;   /* route transitions */

--ease-out:    cubic-bezier(0.16, 1, 0.3, 1);   /* springy */
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
```

**Rules**
- Route transitions: 280ms fade + 8px upward drift on entry, 200ms fade out. Exit shorter than entry.
- List entrance: stagger children 40ms apart, 320ms each, `--ease-out`.
- Buttons: 180ms color/border transition, 100ms scale (0.98) on active.
- Cards: 240ms transform on hover, `translateY(-2px)` + shadow bump.
- Skeleton loaders: 1.4s shimmer, always fade to real content in 240ms.
- Never animate `width`, `height`, `top`, `left`. Use `transform` and `opacity`.
- Never block interaction. Cancel any in-flight animation on user input.
- Wrap all keyframe animations in `@media (prefers-reduced-motion: no-preference)`.

## 7. Icons

**Library:** [Phosphor Icons](https://phosphoricons.com/) — outline weight, 20px default, 24px for primary actions. Streamlit has no native Phosphor integration, so we ship inline SVGs via `src/ui/icons.py`.

**Stroke:** 1.5px consistent. **Size tokens:**

```css
--icon-sm: 16px;
--icon-md: 20px;
--icon-lg: 24px;
--icon-xl: 32px;
```

Icons must always pair with text for primary actions (never icon-only for
patient personas). Touch target min 44×44pt including padding.

## 8. Component patterns

- **Buttons**: `--radius-sm` (12px), `--space-3` vertical / `--space-5` horizontal padding, body font 15px 500. Primary = filled with `--accent`; secondary = `--surface-card` + border; tertiary = text-only. No pill buttons except for filter chips.
- **Inputs**: `--radius-sm` border, 1px `--border`, focus ring 4px `--accent-subtle`. Height 48px minimum (patient touch target).
- **Cards**: `--radius-md` (16px), 1px `--border`, `--shadow-1`, `--space-6` padding.
- **Sheets / modals**: `--radius-lg` (24px) top, backdrop `rgba(0,0,0,0.4)` blur 8px.
- **Toasts**: `--radius-pill`, `--surface-card`, `--shadow-2`, auto-dismiss 4s.
- **Progress ring**: 6px stroke, `--accent` on `--accent-subtle` track, animated draw on mount.

## 9. Forbidden patterns

Reject these in code review. They break the design system regardless of skill or intent.

- ❌ Emoji as structural icons (only allowed in user-generated content)
- ❌ Hardcoded hex outside `MASTER.md` and theme files
- ❌ Sharp corners (radius < 8px)
- ❌ Pure black `#000` on pure white `#FFF` (except `high-contrast` theme)
- ❌ Gradients (except one carefully-chosen hero gradient per theme, optional)
- ❌ Glassmorphism / heavy backdrop blur (breaks warmth)
- ❌ AI purple/violet/pink accents
- ❌ Body text below 17px
- ❌ Buttons without hover/focus/active states
- ❌ Animations without `prefers-reduced-motion` guards
- ❌ Streamlit `st.balloons`, `st.snow`, `st.toast` with emoji

Ship-blocking. From the skill's Pre-Delivery Checklist, adapted for this product:

- [ ] Every color reference uses a `--*` token
- [ ] Every theme × role combo passes WCAG AA (`high-contrast` passes AAA)
- [ ] Every screen tested at 375, 768, 1024, 1440 widths
- [ ] Every animation has a `prefers-reduced-motion` fallback (instant transitions)
- [ ] Every button has visible focus ring and 44×44pt touch area
- [ ] Every route reachable by direct URL (browser back works)
- [ ] Body text ≥ 17px everywhere; hero copy uses optical-size Fraunces
- [ ] No emojis in structural UI
- [ ] Theme picker persists across sessions
- [ ] No layout shift on load (reserved space for async content)
